# kai

Kai 的三个练习小程序，都是单文件、无依赖、离线可用的 HTML。

| 地址 | 内容 |
|---|---|
| https://jessielzh.com/kai/spelling | Spelling trainer — 听写，电脑读单词，他拼出来 |
| https://jessielzh.com/kai/history | History key vocabulary — 只练"会读"和"知道意思"，不拼写 |
| https://jessielzh.com/kai/bmc-1000 | BMC 1000 Words — Read / Understand / Spell（Warm up + Test），按书、unit、Part 练 |

所有页面都带 `<meta name="robots" content="noindex">`，不进搜索引擎。

改完直接 push 到 `main`，GitHub Pages 会自动更新。
